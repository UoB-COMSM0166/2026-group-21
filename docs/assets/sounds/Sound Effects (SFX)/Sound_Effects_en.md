# Musci Assets

## 1. Ball & Interaction

| **Name**        | **Trigger Scenario / Function**             | **Audio Description / Reference**                            |
| --------------- | ------------------------------------------- | ------------------------------------------------------------ |
| **Light Tap**   | Net shot, gentle block, drop shot.          | Crisp, short, light impact.                                  |
| **Heavy Smash** | Power smash, kill shot.                     | Explosive, tearing sensation (whip-crack quality).           |
| **Frame Hit**   | Mishit, ball hitting the racket frame.      | Dull, hollow, woody sound.                                   |
| **Fast Travel** | Ball passing at high speed.                 | Sharp air-cutting "swoosh" or whistle (pitch shifts based on speed). |
| **Spin/Slice**  | Heavy spin shot, slice.                     | Short, intense friction/rubbing sound.                       |
| **Net Cord**    | Ball grazing or hitting the top of the net. | Metallic vibration, taut string tension.                     |
| **Body Hit**    | Hitting the opponent / Face shot.           | "Meaty" thud, muffled impact (combat-style feedback).        |

## 2. Crowd Dynamics 

| **Name**          | **Trigger Scenario / Function**                          | **Audio Description / Reference**                            |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| **The "Ooh"**     | Missed opportunity, near miss, barely failing to return. | Sharp intake of breath, collective sigh, synchronized disappointment. |
| **The "Whoa"**    | Flashy skill activation, spectacular point scored.       | Amazement, shock, collective awe.                            |
| **Laughter**      | Stamina depletion, character tripping/falling.           | Short burst of laughter, mocking tone (sitcom style).        |
| **Rhythmic Clap** | Match point, rallying the player.                        | Heavy, rhythmic beat (stadium clap / "We Will Rock You" style). |
| **Heckling**      | Foul play, passive/stalling gameplay.                    | Booing, whistling, negative jeering.                         |

## 3. Environmental Modifiers

| **Name** | **Trigger Scenario / Function**          | **Audio Description / Reference**                       |
| -------- | ---------------------------------------- | ------------------------------------------------------- |
| **Gust** | Strong wind affecting ball trajectory.   | Howling, whooshing (sudden gusts).                      |
| **Hot**  | Summer setting / High-temperature court. | Continuous background buzzing of cicadas/insects.       |
| **Rain** | Rainy weather setting.                   | Wet surface sounds, water splashing/slapping on impact. |
