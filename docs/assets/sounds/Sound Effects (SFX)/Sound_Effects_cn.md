# 音效

# 1. Ball & Interaction

| **子分类** | **音效名称**    | **触发场景/功能** | **建议听感/描述**         |
| ---------- | --------------- | ----------------- | ------------------------- |
| **击球**   | **Light Tap**   | 网前小球、轻挡    | 轻微、短促                |
| **击球**   | **Heavy Smash** | 大力扣杀、杀球    | 爆裂、撕裂感 (类似鞭子)   |
| **击球**   | **Frame Hit**   | 打框失误          | 沉闷、空洞、木质感        |
| **飞行**   | **Fast Travel** | 球高速飞过        | 尖锐的破空声 (随速度变调) |
| **飞行**   | **Spin/Slice**  | 强烈旋转/切球     | 短促的摩擦声              |
| **碰撞**   | **Net Cord**    | 擦网/触网         | 金属震动、紧绷感          |
| **碰撞**   | **Body Hit**    | 击中对手/打脸     | 肉感、闷响 (战斗反馈)     |

## 2. Crowd Dynamics 

| **反应** | **The "Ooh"**     | 遗憾、差一点接到  | 倒吸一口凉气、整齐的叹息 | `crowd gasp`, `audience sigh`, `shocked reaction` |
| -------- | ----------------- | ----------------- | ------------------------ | ------------------------------------------------- |
| **反应** | **The "Whoa"**    | 华丽技能/精彩得分 | 惊叹、震撼               | `crowd wow`, `amazed reaction`, `crowd awe`       |
| **反应** | **Laughter**      | 耐力耗尽、摔倒    | 短促的笑声、嘲笑         | `short laugh`, `sitcom laugh`, `audience chuckle` |
| **节奏** | **Rhythmic Clap** | 关键分鼓舞        | 有节奏的重拍             | `stadium clap beat`, `we will rock you clap`      |
| **节奏** | **Heckling**      | 犯规/消极比赛     | 嘘声、口哨               | `crowd boo`, `whistle`, `heckle`                  |
